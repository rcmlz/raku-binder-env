# raku-binder-env

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/rcmlz/raku-binder-env/main?urlpath=lab)

---

Use a repo like this one as a Binder environment-repo via [nbgitpuller](https://nbgitpuller.readthedocs.io/en/latest/link.html) to quickly launch your actuall notebook-repo(s).

- [Jupyter::Chatbook Examples](https://mybinder.org/v2/gh/rcmlz/raku-binder-env/main?urlpath=git-pull%3Frepo%3Dhttps%253A%252F%252Fgithub.com%252Fantononcube%252FRaku-Jupyter-Chatbook%26urlpath%3Dlab%252Ftree%252FRaku-Jupyter-Chatbook%252Feg%252F%26branch%3Dmaster)

- [Jupyter::Kernel Examples](https://mybinder.org/v2/gh/rcmlz/raku-binder-env/main?urlpath=git-pull%3Frepo%3Dhttps%253A%252F%252Fgithub.com%252Fbduggan%252Fraku-jupyter-kernel%26urlpath%3Dlab%252Ftree%252Fraku-jupyter-kernel%252Feg%252Fhello-world.ipynb%26branch%3Dmaster)

---

Please consult the [postBuild](postBuild) script and the [postBuild.d](postBuild.d) folder to see how [Rakubrew](https://rakubrew.org/), [Jupyter::Chatbook](https://github.com/antononcube/Raku-Jupyter-Chatbook) and [Jupyter::Kernel](https://github.com/bduggan/raku-jupyter-kernel/) was installed and initialized.
